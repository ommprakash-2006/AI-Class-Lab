## 📌 About This Repository

Welcome to **AI-Class-Lab**! 👋

This repository contains Python implementations of Artificial Intelligence lab programs. It is created as part of my learning journey to understand AI concepts through practical coding.

The programs focus on search algorithms, problem-solving techniques, game-playing algorithms, and classical AI problems. Each implementation aims to be simple, readable, and easy to understand for students and beginners.

## 🎯 Objectives

- Understand fundamental concepts of Artificial Intelligence.
- Implement AI algorithms using Python.
- Learn search strategies and problem-solving techniques.
- Explore game-playing algorithms and decision-making.
- Practice writing, executing, and debugging Python programs.
- Build a useful reference for AI lab practicals and examinations.

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your computer.
- A code editor such as Visual Studio Code, or any Python IDE.
- Basic knowledge of Python programming.

### Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/ommprakash-2006/AI-Class-Lab.git
```

Navigate to the project directory:

```bash
cd AI-Class-Lab
```

### Run a Program

Navigate to the folder containing the desired Python program and execute it:

```bash
python filename.py
```

Replace `filename.py` with the actual name of the program you want to run.

On some systems, you may need to use `python3` instead of `python`.

## 🧠 Concepts Practiced

Through these programs, I aim to develop an understanding of:

- **Search Algorithms:** BFS, DFS, and A* Search.
- **Game-Playing Algorithms:** Min-Max and Alpha-Beta Pruning.
- **Backtracking:** Solving constraint-based problems such as the 8-Queen Puzzle.
- **State-Space Search:** Solving the Water Jug Problem.
- **Game Development:** Implementing Tic-Tac-Toe.
- **Optimization:** Finding low-cost routes in the Travelling Salesman Problem.

## 📖 Learning Approach

Each program is designed to help me:

1. Understand the problem statement.
2. Learn the underlying algorithm.
3. Implement the solution in Python.
4. Test the program with sample inputs.
5. Analyze the output and understand the logic.
